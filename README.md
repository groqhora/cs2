# 3D mashq xaritasi

## Fayllar
- index.html, style.css, main.js: ilova
- maps/map.glb: xaritangiz (oʻzingiz qoʻyasiz, nomi aynan map.glb boʻlsin)

Xarita boʻlmasa, oddiy blok xarita ochiladi. Oʻz .glb faylingizni boshlang'ich ekrandagi tugma orqali ham ochsangiz boʻladi.

## GitHub Pages ga joylash
1. github.com da yangi repository oching (masalan, cs2-mashq), Public.
2. "Add file" > "Upload files" orqali shu papkadagi hamma fayllarni (maps papkasi bilan) tashlang. Fayl 25 MB dan kichik boʻlishi kerak.
3. Settings > Pages > Source: "Deploy from a branch", Branch: main, / (root) > Save.
4. 1-2 daqiqadan keyin sahifa https://FOYDALANUVCHI.github.io/cs2-mashq/ manzilida ochiladi.

## Muhim
- Xarita litsenziyasini tekshiring (masalan, CC) va muallifni koʻrsating.
- Kompyuterda lokal ochish uchun papkada `python -m http.server` ishga tushirib, http://localhost:8000 ni oching (fayldan toʻgʻridan-toʻgʻri ochilsa, map.glb yuklanmaydi).
